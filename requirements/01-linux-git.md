# 01 – Linux & Git

## Linux
Run the solution on Linux and create `evidence/linux.md` showing commands/output or concise evidence for:
- OS/kernel identification;
- CPU, memory and disk utilization;
- listening ports and relevant processes;
- DNS/network connectivity checks;
- application/container logs;
- identifying the process consuming the most memory;
- identifying disk usage by directory; and
- a simple repeatable health-check script.

Explain briefly how you would investigate high CPU, low disk space, an unreachable API, and a repeatedly terminating process.

## Git
Use Git as part of your actual workflow. Your history itself is the evidence. Include a tag named `submission-v1.0` on the final version. Document any branch/merge strategy you used.
