# 06 – GUI Test Automation

Provide a minimal browser UI for the application and automate key journeys using Playwright, Selenium, Cypress or an equivalent framework.

Automate at least:
1. Open/login to the application if authentication exists.
2. Search for a transaction.
3. Create/submit a test payment or equivalent business action.
4. Validate a successful result.
5. Validate at least one negative/error scenario.

The tests must be runnable using a documented command and should use stable selectors rather than fragile timing-only logic. Include evidence/report output from a completed run.

Explain how you would integrate the tests into CI and which tests should run on every release versus a larger regression suite.
