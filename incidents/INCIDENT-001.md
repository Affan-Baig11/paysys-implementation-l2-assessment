# INCIDENT-001 – Intermittent Transaction Search Failure

**Priority:** P2  
**Reported by:** Client Operations

Users report that transaction searches intermittently return HTTP 500. Some transaction IDs work while others fail.

## Your task
Investigate the problem and create `investigation/INCIDENT-001-RCA.md` containing:
- observations and reproduction steps;
- evidence gathered;
- hypotheses considered;
- root cause;
- immediate corrective action;
- permanent corrective/preventive action; and
- validation performed after the fix.

Where your own implementation does not naturally reproduce this fault, deliberately introduce a realistic defect, demonstrate the failure, and then diagnose/fix it. Clearly document what was introduced; the quality of the investigation is being assessed.
